GPT_Dragon_girl_transformation本地养成模块 v2（纯 ESM）

入口 index.mjs；类型 index.d.ts；测试 life.test.mjs。
模块无文件读写、网络请求、定时器、自动启动或模型控制。它只接收普通数据并返回新的JSON可序列化状态。
Electron主进程负责选择本应用自己的状态存储位置；不要读取其他个人文件。不要把状态上传。

接口
createLifeState({now?,timeZone?})：新状态。
normalizeLifeState(value,options)：丢弃未知字段、修正范围、迁移v1存档；未知版本回退新状态。不会修改原输入。
parseLifeState(json,options) / serializeLifeState(state,options)：坏JSON安全回退；不要直接信任文件中的字段。
applyInteraction(state,'click'|'pet',options)：返回{state,result}。
claimGreeting(state,options)：返回{state,result}；result.greeting为本时段首次问候，重复或睡眠时为null。
getGreeting(options)：仅查看当前时段问候，不记录已问候。
setTemporaryMode(state,'sleep_mode'|null,{now?,timeZone?,restBaseline?})：进入/退出持续休息；durationMs兼容参数被忽略。restBaseline接收当前tasks，只保存id/turn哈希。
getEffectiveMode(state,options)：sleep_mode或null；游戏陪伴模式已移除。
getProgression(state,options)：level、affectionLevel、tier、reactionLevel、levelXp、levelXpCost、totalXp、progressionXp、xpToNextLevel、progress、isMax等展示值。
xpForLevel(level)：到达某等级的累计成长XP；LEVEL_COSTS为Lv1至Lv99升级所需成本数组。
tierFromLevel(level)：Lv1-3为low、Lv4-6为mid、Lv7-100为high。

options.now是Unix毫秒；省略用Date.now()。timeZone省略使用本机时区，非法时区回退UTC。
宿主应对所有调用使用同一timeZone选项，避免跨调用切换时区造成自然日边界变化。
问候时段：05:00–10:59早安，11:00–17:59午安，18:00–04:59晚上好；每个本地日期/时段最多一次。
睡眠会暂停自动问候和互动奖励，轻触仍可返回sleepy_reaction语义反馈；不会自动退出睡眠。

养成规则
点击/抚摸每次奖励2经验。奖励间隔10秒；视觉反馈最多每350毫秒一次。
每天最多30互动经验；达到每日上限后不再累积。旧affection字段仍保存，作为兼容资料，不再用于展示或反应解锁。
好感1至100级。Lv1→2至Lv10→11成本依次为6、8、10、12、14、16、18、20、22、24XP；之后每级固定24XP。
累计门槛：Lv4为24XP、Lv7为66XP、Lv10为126XP、Lv100为2286XP。
Lv100显示MAX，progress=1、nextLevelXp=null、xpToNextLevel=0、levelXpCost=0，不再奖励经验，防止条溢出。
反应目录使用getProgression(state).reactionLevel（等级+本级进度），例如4.5表示Lv4进度50%。
读取v1存档保留原totalXp和旧affection。旧等级/好感保底通过migrationBonusXp记录一次性成长信用，progressionXp=totalXp+migrationBonusXp；不会反复发迁移奖励。
跨本地自然日重置每日预算；系统时钟回退不会重置预算或绕过奖励间隔。
休息没有时间限制，状态保存kind、startedAt和restBaseline，不写expiresAt。用户主动退出，或宿主通过rest-wakeup.mjs检测到休息后开始的新任务/新轮次时，调用setTemporaryMode(state,null)恢复；同一轮工具活动不会误唤醒。
仍在生效的v1旧睡眠迁移为持续休息，已过期旧睡眠不复活；旧游戏模式直接清除。

接入示例（主进程持有唯一state，按序处理事件，避免多窗口覆盖彼此的经验）
  import { parseLifeState, applyInteraction, claimGreeting, serializeLifeState } from './life/index.mjs';
  const lifeOptions = {timeZone:'Asia/Shanghai'};
  let life = parseLifeState(savedJson, lifeOptions);
  function onPetClick() {
    const update = applyInteraction(life,'pet',lifeOptions);
    life = update.state;
    // 主进程保存serializeLifeState(life)，向renderer发送update.result与getProgression(life)。
    // 对持久化做短暂合并写入；用户退出时刷新。不要每帧写盘。
    return update.result;
  }
  const greeting = claimGreeting(life,lifeOptions); life = greeting.state;
  // greeting.result.greeting?.text可显示气泡；不可宣称模型已有对应动画。

事件边界
petting_reaction、sleepy_reaction、greeting_*、sleep_mode均是语义状态，不是保证存在的Cubism参数或motion文件。
渲染方必须先检查真实模型能力；没有对应绑定时使用文字气泡或普通UI反馈。
新任务唤醒与工作优先级由宿主状态机决定；本模块不会启动或停止Codex任务。
本模块不操作剩余额度，也不推测额度数值。
