# 可以摸摸哪里？ ♡

**v1.0.0 无配音版 · 六个角色部位，七处桌面与饰物互动，以动作、表情和可爱文字回应你。**

把鼠标放到想碰的位置，悬停提示会告诉你这一处可以做什么。轻点触发动作，按住拖动则移动整只桌宠；拖动结束不会额外触发一次摸摸。默认尺寸比较小，可以先用 `Ctrl` + 滚轮放大再体验细小部位。

## 慢慢熟悉的六个部位

| 点击位置 | 怎样找到 |
| --- | --- |
| 头顶 | 头顶的头发区域，避开龙角 |
| 龙角 | 头发两侧的白色节纹龙角 |
| 脸颊 | 紫瞳下方的脸颊区域 |
| 小手 | 桌边露出的手背；疲惫形态也可轻碰托腮手部 |
| 脚尖 | 桌面下的腿部与鞋面 |
| 尾巴 | 角色旁的龙尾 |

每个部位有 **15 种**互动：慢慢熟悉、娇羞、亲近与俏皮三档，每档 **5 种**。六个部位共 **90 种**，不是简单换一句文字；每种都有自己的动作节奏与组合。

- **Lv.1–3：** 慢慢熟悉，动作逐步解锁；脚尖与尾巴会小小抗议，摸头等新增部位以拘谨、轻点头和小幅躲闪回应。
- **Lv.4–6：** 配合脸红和羞怯反应，悄悄拉近距离。
- **Lv.7 起：** 亲昵点头、开心回应与轻巧逗趣；Lv.10 时全部 90 种解锁。
- **Lv.100：** 显示 MAX，已经解锁的互动继续保留。

日常点击只从当前阶段已解锁的动作里选择。动作正在播放时不叠加整串新动作，结束后可以再轻点；有多个可选动作时，尽量不与上一次紧邻重复。

完整名称、等级门槛和动作范围见 [90 种互动与解锁表](affection-reactions.md)。

## 桌上的小伙伴

| 点击位置 | 小动作 |
| --- | --- |
| 水杯 | 点画面前方的透明水杯，水面泛起小涟漪与星光 |
| 小植物 | 点显示器旁的花叶，叶片轻轻摇动 |
| 小摆件 | 点桌上白紫色小龙，它轻弹并扑棱小翅膀 |
| 键盘 | 点显示器前的键盘，键面轻轻按下弹回 |
| 笔记本 | 桌上打开的纸页，保留翻页动作 |
| 鼠标 | 握鼠手前的鼠标，保留轻按动作 |
| 耳饰 | 脸旁的紫色垂坠饰物，保留轻晃动作 |

这些小互动不设好感等级门槛，也不计入上方的 90 种角色动作。六个角色部位与新增的水杯、植物、小摆件、键盘支持四种形态；原有笔记本、鼠标与耳饰点击动作目前在工作形态保留。小手与鼠标、键盘分开判断：点手背触发亲密互动，点物品主体触发物品动作。缩放与屏幕左右镜像后，点击位置跟随画面；悬停提示比凭记忆点击旧坐标更准确。

## 不会打断的小规则

经验规则仍是每次有效奖励 2 点、冷却 10 秒、每日最多 30 点。播放动画与获得经验分别判断，因此有动作不一定代表本次还会加经验。

休息期间保持闭眼睡姿，点击只给出简短的困倦文字回应；不会启动日常互动或增加经验。可以从右键菜单选择 **回到工作状态**，也可以等待真实的新任务开始。**休息不会停止 Codex 正在运行的任务。** [查看休息与控制范围](codex-rest-control.md)

桌宠启用鼠标穿透时不能直接触摸，先在右键托盘菜单恢复交互，或使用 `Ctrl` + `Alt` + `Shift` + `D`。桌面云朵显示当前操作或新进度分类；好感度和经验从右键菜单查看，不会挤入云朵里。

新增动作由本程序驱动，未写入原始 `.moc3`。放到其他播放器时不会自动获得这些互动。
