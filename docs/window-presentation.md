# GPT_Dragon_girl_transformation 的朝向、云朵与系统托盘

适用于 v1.0.0 无配音版。

软件与项目名称为 **GPT_Dragon_girl_transformation**。已有安装目录不必仅因名称变化而移动；Hooks 与随启动快捷方式仍应指向实际安装位置。

## 跟随所在位置的朝向

桌宠中心位于当前显示器左半边时保持原朝向，位于右半边时镜像显示。拖到另一块显示器后，按新显示器的中线判断，支持位于主屏左侧或上方的屏幕。

中线附近有 8 个逻辑像素的缓冲区，避免慢慢拖动时来回翻转。缩放后也会重新判断。朝向只改变显示与互动坐标，不修改模型、贴图、任务或成长记录。

任务云朵始终跟随画面中的电脑上方，右侧镜像后移到对应的左上方。云边、小圆点和提示框装饰跟随翻转，文字与数字保持正常阅读方向。靠近屏幕边缘时，提示窗口会留在可见范围内。

## 轻点云朵，回到对应对话

云朵显示当前操作，或 Codex 已发送进度与回复的简短分类。轻点主体，或键盘聚焦后按 Enter / 空格，先播放约 **0.56 秒**的云片破碎动画，再返回被点击提示对应的 Codex 对话；开启系统“减少动态效果”时动画缩短。若跳转失败则还原提示并显示短说明，不会改为打开别的聊天。拖动云朵只移动桌宠，不触发破碎或跳转。

从点击起约 **6.5 秒**后，仍是同一个监听任务、任务继续运行且状态未过期时，气泡会重新出现；已结束或状态失效的任务保持收起。切换监听任务，或使用角色、托盘菜单 **显示任务气泡**，可立即恢复。这个短暂收起不修改保存的气泡显示偏好。

当程序已追踪到任务结束，独立的小 `×` 可只让云朵碎成小云片并临时收起，不打开聊天。工作中、等待用户操作或任务状态未知时，不显示这个结束专用按钮；主体点击的破碎与跳转不表示任务已经完成。通过小 `×` 收起后，新任务开始、任务恢复运行或收到新进度与回复会让云朵再出现。临时收起不改变右键菜单中的显示偏好，也不增加好感度；收起后的透明区域不会阻挡桌面点击。

鼠标悬停或键盘聚焦时的减号仍可手动隐藏任务气泡。使用角色或托盘右键菜单 **显示任务气泡**，可以再次显示。手动隐藏属于显示偏好，与任务结束后的临时收起分别处理。

## 系统托盘入口

### 切换监听任务

右键角色、任务气泡或托盘，选择 **切换监听任务**。选 **自动跟随任务**，会继续跟随近期活动；选列表中的任务，则固定监听对应会话。

列表从同一个本机 Codex 用户数据目录发现最近最多 200 个未归档主聊天，不按项目目录限制范围；优先显示聊天名称，辅以短编号和状态，同目录下的不同会话分别列出。无名称时回退项目目录名。当前选择有勾选标记，偏好保存在本地，重启后保留；固定任务结束后不会自动跳到其他会话，可在同一菜单切换或恢复自动跟随。数据不可访问或状态不完整时显示未知，详细接入方法见 [安装说明](installation.md#codex-接入与排查)。

监听选择同时作用于工作状态、任务云朵、提问提醒和点击跳转。云朵内容仍只有正在做什么，不加入目录、好感度或切换按钮。

休息期间检测到新启动的 Codex 任务时，仍按原有规则唤醒并跟随该新任务。

### 隐藏在托盘中

启动后，GPT_Dragon_girl_transformation 仍显示在桌面上，但不会占用底部任务栏的应用按钮。系统托盘保留小图标，可在 Windows 的隐藏图标面板中找到。

- 双击托盘图标，恢复显示与交互。
- 右键托盘图标，调整缩放、气泡、休息与置顶等选项。
- 选择 **退出**，关闭桌宠。
- `Ctrl` + `Alt` + `Shift` + `D` 也可恢复显示与交互。

这些改动不会改变原有的虚拟桌面固定、输入法与系统面板优先显示规则。休息功能仍只控制 GPT_Dragon_girl_transformation；Codex 任务停止接口的现有限制见 [休息与唤醒说明](codex-rest-control.md)。
