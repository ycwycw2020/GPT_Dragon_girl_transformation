# v1.0.0 · 小龙娘的全局工作桌

**这次重点是正确发现和跟随 Codex 的聊天，不再被桌宠所在目录限制。**

## 任务监听更新

| 之前 | v1.0.0 |
| --- | --- |
| 主要依赖近 24 小时的 Hooks 缓存 | 只读本机 Codex 全局聊天索引，结合轮次生命周期、事件检查和 Hooks |
| 菜单以目录名区分任务，容易看成监听位置错误 | 优先显示真实聊天名称，保留短编号和状态；同目录聊天分别列出 |
| 未捕获 Hooks 的项目可能遗漏或状态陈旧 | 不限项目磁盘、日期或工作目录；没有可靠状态时显示未知 |
| 旧任务事件可能与新任务状态混淆 | 按会话和轮次身份区分；完成、中断和新开始分别处理 |

自动跟随优先活动聊天，也可以从右键菜单固定监听。监听选择同时作用于角色工作状态、任务云朵、提问提醒与点击跳转，并在重启后保留。

发现范围为同一个本机 Codex 用户数据目录内最近最多 **200 个未归档主聊天**。内部子代理不重复列作项目；未同步到本机或无法访问的数据不保证可见。自定义 `CODEX_HOME` 的使用方法见 [安装说明](installation.md#codex-接入与排查)。

## 继续保留的小细节

- 白紫工作桌与固定龙娘形象，一个 Cubism 工作模型和三个程序驱动的精力形态。
- 轻柔呼吸、双眼眨眼、尾巴与腿部动作，以及六个角色部位的 90 种分档互动。
- 好感 Lv.1–100，满级 MAX；休息不设倒计时，明确的新任务可唤醒。
- 电脑上方的粉白思考泡、已结束任务的云朵破碎、屏幕左右镜像且文字正常。
- 提问提醒和新进度可点击返回对应聊天；新建聊天入口只打开输入界面。
- 托盘入口、隐藏任务栏按钮、自由拖动与缩放、本地偏好保存。

**此版本没有配音、语音菜单或音频生成服务。**

### 点击云朵的小变化

点击任务思考泡时，先播放约 **0.56 秒**的破碎动画，再回到被点击提示对应的 Codex 聊天。从点击起约 **6.5 秒**后，同一任务仍在运行且状态有效时恢复气泡；已结束或状态失效时保持收起。切换监听任务或通过菜单显示气泡可立即恢复，跳转失败则还原提示，拖动不触发跳转。任务结束后的独立小 `×` 保留只点碎、不跳转的行为。

## 当前边界

**休息仍只控制桌宠，不能停止 Codex 正在执行的任务。** 任务发现、提问 Hooks 和额度读取是三个不同来源；其中一项正常不代表其他两项必然连接。数据库或接口暂不可用时保留未知状态，不伪造运行或停止结果。

多个形态与触碰增强包含程序驱动实现，尚未全部回写到 Cubism 源工程；单独在其他播放器中加载 `.moc3` 不能复现全部效果。当前验证平台为 Windows x64，macOS、Linux 和其他 Codex 安装形式暂未完整验证。
